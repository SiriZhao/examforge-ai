# 截图目录

这里用于存放 GitHub README 中展示的软件截图和演示 GIF。

推荐文件：

- `home.png`：首页、上传区和空结果区
- `report.png`：生成结果总览
- `chapter-priority.png`：章节优先级
- `mock-exam.png`：模拟卷
- `demo.gif`：从上传到导出的简短演示

截图流程：

1. 运行 `.\start.bat`。
2. 打开 `http://127.0.0.1:5173`。
3. 使用 `examples/` 中的虚构示例文件，避免截图包含真实课程资料。
4. 建议使用 1440x900 或 1920x1080 分辨率截图。
5. 将 README 中的占位图片替换为本目录图片。

不要提交包含真实学生数据、真实试卷、私有 API Key 或版权课程资料的截图。
